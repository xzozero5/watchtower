# Watchtower Brand Assets & Logo Guide

> **Official Project Brand Identity [CONFIRMED 2026-10-31]**  
> **Symbol:** The Sea Lighthouse with Midnight Navy Dome Roof and Warm Coral & Ivory Stripes (`Option 3B-3`).  
> **Metaphor:** A steady, vigilant beacon standing strong amidst the waves, guiding tech operations safely through incidents and system storms.

## 3. กฎการนำสีไปใช้ใน UI (Alert Discipline — PRD §10) `[CONFIRMED 2026-10-31]`

* **สีแดงแบรนด์ (`#E5594A`):** ใช้เฉพาะในตัวโลโก้ประภาคารเท่านั้น **ห้ามนำไปใช้เป็นสีปุ่มทั่วไป (Primary Button) ในแอปเด็ดขาด** เพื่อไม่ให้ผู้ใช้สับสนกับสีแจ้งเตือนวิกฤตระดับ **P1 Incident Alert** (Severity Red)
* **ปุ่มหลักของระบบ (Primary Action Button):** ใช้ **สีกรมท่า (Midnight Navy `#0F172A` / `#1E293B`)** แทน ตามหลัก Alert Discipline
* **ไม่มีคำโปรย / Badge แปลกปลอม:** ตัวโลโก้ทางการมีเฉพาะรูปประภาคารและคำว่า "Watchtower" บรรทัดเดียวเท่านั้น ไม่มี badge สองข้าง หรือคำโปรยภาษาอังกฤษ เพื่อความเรียบหรูและสเกลใช้งานได้คมชัด
