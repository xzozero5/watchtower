## พื้นผิวใหม่ที่ตรวจแล้วไม่พบปัญหา
- **golden preview** (`GET tickets/:id/golden/preview`, T-306i): `ai.golden.manage` + `tickets.viewRow` (RBAC/org scope เดิม), message ต้องเป็นของ ticket นั้นและเป็น outbound public ที่ส่งแล้ว, ไม่เขียนอะไร, masking เป็น local (ไม่มี LLM/NER call) จึงไม่เป็นช่องทาง cost · ไม่ลง audit (คืนข้อความที่ redact แล้วซึ่ง lead อ่านได้อยู่แล้ว) — ยอมรับได้
- **403 `reason`** (B-011): ส่งเฉพาะ code รูป `^[a-z][a-z0-9_]{0,63}$` ของ `policy_denied`; reason ทั้งหมดเป็น code เชิงนโยบาย (`report_not_green`, `pinned`, `kb_publisher_is_author`, ...) ไม่มีข้อมูลลูกค้าหรือการมีอยู่ของ resource ที่ผู้เรียกไม่มีสิทธิ์
- **step-up CSRF/ผูก session:** state cookie ลงนาม + PKCE + nonce, step-up ผูก `sessionId`+`userId` ใน cookie, ผลบันทึกบน session ที่ขอเท่านั้น; คนขโมย cookie ยังต้องผ่าน Google `prompt=login`
- DB จาก app role: UPDATE stage ตรง, INSERT promotion approved, UPDATE `ai_draft` เป็น `auto_approved` นอก stage 3, แก้/ลบ `ticket_event`, UPDATE `golden_answer.shareable` ถูกปฏิเสธทั้งหมด `[TESTED]`
